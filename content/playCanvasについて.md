# playCanvasについて
## 必要な準備（前提条件）

まずはPCに以下が入っている必要があります。

- **Node.js**（まだ入っていない場合は、公式サイトからLTS版をインストールしてください）
    
- **VS Code** などのコードエディタ
    

## ステップ1：必要な情報の用意（PlayCanvas側）

ローカルからPlayCanvasにアクセスするために、2つの情報（トークンとプロジェクトID）が必要です。

1. **APIトークンの発行**
    
    - PlayCanvasにログインし、アカウント設定（Account Settings）の「API Tokens」を開きます。
        
    - 適当な名前（例: `cli-token`）をつけてトークンを生成し、表示された長い文字列を**メモ帳などにコピー**しておきます（一度閉じると二度と見られません）。
        
2. **プロジェクトIDとシーンIDの確認**
    
    - 先ほどのURL `https://playcanvas.com/editor/scene/2537794` を見ると、必要なIDが分かります。
        
    - **Project ID:** （ブラウザのプロジェクトのダッシュボードを開いたときのURLに含まれる数字、または設定から確認できます。通常7桁前後の数字です）
        
    - **Scene ID:** `2537794`
        

## ステップ2：ローカルフォルダの作成と設定

パソコン（Windows）のコマンドプロンプトやPowerShellを開き、プロジェクト用のフォルダを作って設定していきます。

### 1. フォルダを作成して移動する

Bash

```
mkdir playcanvas-local
cd playcanvas-local
```

### 2. 初期化してツールをインストールする

Bash

```
npm init -y
npm install -g playcanvas-cli
```

※ `-g` をつけることで、PCのどこからでも `playcanvas` コマンドが使えるようになります。

### 3. 設定ファイルの作成

フォルダの直下に **`playcanvas.json`** という名前のファイルを新規作成し、以下の内容を貼り付けます（先ほどメモした情報に書き換えてください）。

JSON

```
{
  "accessToken": "あなたのAPIトークンをここに貼り付け",
  "projectId": 123456, // あなたのプロジェクトID（数字）
  "scenes": [2537794],
  "branchId": "master", 
  "scripts": {
    "directory": "scripts" 
  }
}
```

※ `"directory": "scripts"` としておくと、ローカルの `scripts` というフォルダの中身が自動同期されます。なので、同じ場所に `scripts` という名前の空フォルダを作っておいてください。

## ステップ3：同期して開発スタート！

準備ができたら、コマンドプロンプトで以下のコマンドを実行します。

Bash

```
playcanvas watch
```

このコマンドを実行すると、ツールがローカルのファイルの監視（Watch）を始めます。

- **これで何ができる？**
    
    ローカルの `scripts` フォルダの中に、VS Code等で `test.js` を作ったり、Geminiに書かせたコードを保存したりすると、**ツールがそれを検知して、自動でブラウザ（クラウド）側のPlayCanvasへ一瞬でアップロード**してくれます。
    

あとは、ブラウザでPlayCanvasのEditorを開いたまま、手元のエディタでコードを書くだけです。コードを書き換えて保存し、PlayCanvasの「Launch（▶）」ボタンを押せば、すぐに最新のコードでテストプレイができます。

この設定を進める上で、詰まりそうなポイントや「プロジェクトIDが分からない！」などがあれば、いつでも聞いてくださいね。
