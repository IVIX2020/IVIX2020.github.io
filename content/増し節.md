**親字**:: 生み字をした時に基となった言葉
**生み字**::特定の字句の母音を引き延ばして続けて生まれたモーラ

**ゴマ**:: 詞章の右側に一字ごとに付けられた謡の長さの単位

## ゴマの種類
 - 引き以外
	 - 回し
	 - 呑み
	 - 振り
	 - 中回し
 - 引き

## 基本形

| 1   | 2   | 3   | 4   | 5   | 6   | 7   | 8    |
| --- | --- | --- | --- | --- | --- | --- | ---- |
|     |     |     |     |     |     |     | ,,,と |
| …り  | なく  | …こ  | えす  | …ゆ  | めさ  | ませ  | ◻︎   |

## 2字目回しの変化形

|           |     |     |     |     |     |     |     |
| --------- | --- | --- | --- | --- | --- | --- | --- |
| 1         | 2   | 3   | 4   | 5   | 6   | 7   | 8   |
|           |     |     |     |     |     |     | …と  |
| り [**イ**] | なく  | …こ  | えす  | …ゆ  | めさ  | ませ  | ◻︎  |
- 奇数拍頭のモチの部分に直後の字が「寄せ」られる
- 生み字が本来の字の場所に続く

## 他の字を回した場合の変化系

　１　２　３　４　５　６　７　８
と＿りなく＿こえす＿ゆめさませ◻︎　基準句の基本形
と＿りなく**こオえ**す＿ゆめさませ◻︎　５字目回し
と＿りなく**こえエ**す＿ゆめさませ◻︎　６字目回し

## モチの直前の字（４、７）を回す場合
　１　２　３　４　５　６　７　８
と＿りなく＿こえす＿ゆめさませ◻︎　基準句の基本形
と**りなくーウ**こえす＿ゆめさませ◻︎　４字目回し
と＿りなく**こえすーウ**ゆめさませ◻︎　７目回し

ーー。いつ**もオ**じは＿かくぞかし◻︎
ーー。いつも**じイ**は＿かくぞかし◻︎
ーー。いつもじは**ーア**かくぞかし◻︎
ーー。いつ＿もじは**かア**くぞかし◻︎
ーー。いつ＿もじは**かくウ**ぞかし◻︎
ーー。いつ＿もじは**かくぞオ**かし◻︎
ーー。いつ＿もじは＿かくぞ**かアし**
ーー。いつ＿もじは＿かくぞ**かしイ**
